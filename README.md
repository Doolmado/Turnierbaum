# Turnierbaum

Turnierseite mit Single und Double Elimination. Jeder Besucher kann Teilnehmer, Seeding und Ergebnisse eintragen. Die Daten werden nur im eigenen Browser gespeichert (localStorage). Mit "Sichern" und "Laden" lässt sich ein Turnier als Datei exportieren und wieder einlesen.

## Veröffentlichen
Dateien `index.html` und `.nojekyll` in den Hauptzweig legen, dann unter Settings, Pages den Branch `main` mit Ordner `/ (root)` aktivieren.
